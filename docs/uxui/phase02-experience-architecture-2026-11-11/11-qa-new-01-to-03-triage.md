## QA-NEW-03 geometry detail

In the exact failing Chromium viewport, after Playwright scrolls the iframe into view, outer Studio `scrollTop=280`; iframe rectangle is `x=232, y=0, width=380, height=583`, so only 390px of its height can be visible. The toolbar is then above the viewport, but `scrollTop=0` brings all 12 visible Studio actions into the viewport and center hit testing passes; `scrollTop=489` reaches the preview bottom. The loaded iframe contains the fixture heading. This is a scroll-based workspace. The ratio says nothing about whether the user can scroll or act. At 820×430 the analogous ratio is about 0.738; at 768×390 about 0.669. Desktop at 1440×900 had full preview visible in the probe. WebKit's actual frame height differed slightly (575px), which reinforces testing behavior instead of one geometry ratio.

The probe observed `document.scrollingElement`/iframe height but did not certify every authored invitation interaction or 200% text scaling. The simulated 320px external link briefly appeared absent when checked before render settled; after explicitly waiting for the exact accessible link, it was present in all three engines, so that early observation is a fixture timing issue and is not classified as a product defect. There was no evidence of horizontal document overflow or JavaScript errors in these probes. Physical device toolbars, safe areas, screen-reader navigation and production data remain unverified.
