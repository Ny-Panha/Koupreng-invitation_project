# Studio usability

Click-to-edit is opt-in in the preview tools. Only an allowlisted stable section ID crosses the existing session-bound iframe channel. Origin, exact source window, nonce and message schema are all checked. The child uses fixed local selectors; it does not accept selectors or URLs from messages. Form focus and section expansion occur only for controls supported by the active template.

Links, opening buttons, RSVP controls, summary disclosures and media controls keep their interactions. Forged messages and unknown section IDs are rejected. A click on a supported family region opens its Studio disclosure and focuses its field without remounting the preview.

Section capability exclusions now explain retained content. Existing persisted section order and keyboard move controls remain exclusive to the renderer that consumes them. Existing portrait focal control and ticket fit/focal/opacity settings remain non-destructive. There is no duplicated crop model.

The existing bounded 25-entry history and one-writer save queue are retained; no global Ctrl+Z override was introduced. Publishing reuses the established readiness checklist, field targeting and authoritative server confirmation. Generic event editing remains in EventDetails.
