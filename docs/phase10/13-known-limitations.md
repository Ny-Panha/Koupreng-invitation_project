# Known limitations and release conditions

This is a code-review/staging candidate, not unconditional production approval. No production deployment, container restart, DNS edit, live migration, bank payment, outgoing email/SMS or private-data export was performed.

Physical iPhone/Safari and Android hardware, virtual keyboard behavior, human screen readers, Khmer editorial/cultural approval, real mobile network CLS/CPU and live Cloudinary/payment/SMTP/OAuth/Telegram providers remain unverified. Docker engine/private-volume backup and restore remain staging operations. Figural Apsara artwork was intentionally deferred pending qualified review.

The machine-readable matrix separates source contracts, populated React probes, fixture browser lifecycle and native HTTP/MySQL evidence. It does not label an adapter-only value or a hidden cover probe as a successful individual field lifecycle. Exhaustive independent real-HTTP editing of all 70 properties in every template is not claimed. Browser automation is representative functional coverage plus shared contract/security tests; further editorial acceptance can use the matrix as a checklist.

Some optional sections are deliberately unavailable in particular designs; their data stays saved. The developer starter is registered infrastructure rather than a published catalog template. Legacy user-selected external fonts remain stored and can fall back locally when unavailable.
