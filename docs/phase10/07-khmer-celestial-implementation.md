# Celestial implementation

Original inline corner vectors frame the opening and hero; Romduol-inspired dividers replace the small diamond ornament in section headings, including the Save the Date context. Decorative vectors are aria-hidden, unfocusable and pointer-transparent. Existing images, garden component structure, opening callback, calendar/program/venue components and server-authorized optional film remain in place.

Motion presets live in the existing optional studioStyle JSON: Minimal, Elegant (default), Cinematic. All variants apply reduced-motion and Save-Data first. Minimal/reduced/data-saving budgets are zero butterflies, four static flowers and zero petals. Elegant has two butterflies/four flowers/one petal on mobile and four/six/two on desktop. Cinematic is capped at nine butterflies/six flowers/six petals per garden. The old desktop opening could create 18 butterflies/16 flowers/16 petals. No historical invitation conversion is needed.

Every garden observes intersection and document visibility. CSS effects pause offscreen/hidden; foreground Framer movement receives an explicit static animation when paused. Existing vines and SVG illustrations are reused. The serialized preference reaches both live and public content adapters.

The bounded model tests cover every opening/normal/transition/closing variant under reduced motion and Save-Data. Browser snapshots are deterministic under reduced motion; performance figures are asset/bundle measurements, not invented Lighthouse or physical-device scores.

The retained 390/1440px browser budget snapshots report 49 SVG nodes and zero active animations under reduced motion. Each mounted normal/closing garden has four static flowers, zero butterflies and zero petals; the offscreen closing garden is paused. These measurements describe that deterministic fixture state, not full-motion CPU performance.
