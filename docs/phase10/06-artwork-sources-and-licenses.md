# New asset provenance

| Asset | Source / creator | Rights and transformations |
|---|---|---|
| CelestialHeritage corner paths and RomduolEmblem | Original Phase 10 project SVG paths in CelestialHeritage.jsx | Newly authored project artwork; no third-party imagery, traced photographs or stock elements. Inline vectors and CSS; no external attribution requirement introduced. |
| Battambang 400/700 | Google Fonts repository, ofl/battambang/Battambang-Regular.ttf and Battambang-Bold.ttf | SIL OFL 1.1, accompanying battambang-OFL.txt retained; converted to WOFF2, family names retained. |
| Noto Sans Khmer variable | Google Fonts repository, ofl/notosanskhmer/NotoSansKhmer[wdth,wght].ttf | SIL OFL 1.1, accompanying notosanskhmer-OFL.txt retained; converted to WOFF2. |

Font source directories: [Battambang](https://github.com/google/fonts/tree/main/ofl/battambang), [Noto Sans Khmer](https://github.com/google/fonts/tree/main/ofl/notosanskhmer). Licenses accompany the shipped fonts in public/fonts/khmer. Asset digests are in the evidence manifest.

Research references (accessed 25 October 2026; inspiration only, no images copied): [APSARA: Angkor Wat](https://apsaraauthority.gov.kh/2021/06/14/angkor-wat/), [UNESCO: Angkor](https://whc.unesco.org/en/list/668), [World Flora Online: Sphaerocoryne lefevrei](https://www.worldfloraonline.org/taxon/wfo-1000029028). The botanical description supports cream/yellow fleshy petals with distinct outer and inner forms. The vector is an interpretation, not a claim of archaeological authenticity.

Canva was not needed. No Canva Pro content, paid stock, protected source photographs or third-party temple images were added. Existing template assets were preserved; this ledger does not relicense or certify historical assets.

Additional default faces were retrieved from the official Google Fonts [Cinzel](https://github.com/google/fonts/tree/main/ofl/cinzel), [Playfair Display](https://github.com/google/fonts/tree/main/ofl/playfairdisplay) and [Koulen](https://github.com/google/fonts/tree/main/ofl/koulen) directories. Each ships its original SIL OFL 1.1 license in public/fonts/template-defaults. Roman/italic variable Playfair, variable Cinzel and regular Koulen were converted to WOFF2 without changing family names. These replace the same families previously fetched by blocking remote CSS imports; they are not a new aesthetic replacement.
