# Repository agent guidance

Begin at the repository root and follow [.agents/ROUTER.md](.agents/ROUTER.md).
Select one primary skill and at most two supporting skills for the active phase;
use [.agents/SKILLS_INDEX.md](.agents/SKILLS_INDEX.md) to find their current paths.

Inspect current source and manifests before editing. Preserve unrelated work,
existing authorization and entitlement boundaries, and applied Flyway migrations.
Use focused edits and risk-based tests. Report the commands actually run and
their results, including failures and environmental limits.

See [CODEX.md](CODEX.md) for the companion workflow and command examples.
