# 22 — Ten React UI Library Reference and License Matrix

## 1. Canonical Reference Libraries
1. **Animate UI:** MIT / Commons Clause. Evaluated for motion-backed accessible buttons; adapted original CSS transitions.
2. **Badtz UI:** Custom terms. Evaluated for interactive cards; rejected due to cursor bloat.
3. **Lightswind UI:** Commercial. Evaluated for layered workbench surfaces; adapted original command bar.
4. **Kokonut UI:** MIT / PRO. Evaluated for compact status indicators; adapted original status badge.
5. **Untitled UI React:** Commercial / Free Community. Evaluated for form density; adapted original field grouping.
6. **shadcn/ui:** MIT. Evaluated for accessible primitives; existing project components retained.
7. **React Bits:** Custom. Evaluated for micro-animations; rejected due to decorative overhead.
8. **Aceternity UI:** Commercial. Evaluated for focus transitions; adapted subtle ring styles.
9. **Magic UI:** MIT. Evaluated for micro-feedback; adapted button press feedback.
10. **Skiper UI:** Commercial ToS. Evaluated for creative layouts; rejected due to scroll conflicts.

## 2. Zero Copied Source or Dependencies
No external library packages or vendor source code were imported or vendored in this phase.
