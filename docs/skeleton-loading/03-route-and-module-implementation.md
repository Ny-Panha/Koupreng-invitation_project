# Integration and preservation

[The route matrix](01-loading-state-matrix.md) covers initial, refresh, partial, error, empty and access decisions. [Changed files](changed-files.txt) is the scoped implementation/test manifest.

Nested Suspense boundaries keep the user/admin shell and authorized event context mounted while a child route loads. Marketing/auth chunk fallbacks stay compact. Public invitation fallbacks contain no host/guest details and do not replace ceremonial template artwork or opening logic once loaded.

Admin resources use request generations, source identity and unmount invalidation. Older results cannot replace newer requests. Transient refresh failures preserve records and expose retry; explicit authorization failures remove them. Independent dashboard report requests reveal separately. RSVP, wishes, notifications, subscription loads and owner report polling have matching guards where changed. Existing guest cancellation/generation behavior is retained.

Reports retain valid data while polling and immediately suppress a report from another event. Export actions are disabled during refresh. Dashboard/report/RSVP authorization failures do not keep displaying protected records. No API path, payment mutation, entitlement rule, currency calculation, backend schema, worker handler or migration changed.

The user's follow-up asked for less visible guidance. RSVP/QR/delivery/media/seating/wishes/profile/notification/team/package introductions and repeated helper paragraphs were trimmed. Guest counts are concise; one small guest page has no pagination bar. Necessary pagination retains accessible labels and selection behavior. Import format/size requirements, leading-zero protection, validation, access/payment states, unsaved-work and save-before-export warnings remain. Authored public invitation wording is untouched.

The final design pass fixes guest search padding, clear-button hit targets, filter labels/chevrons, responsive status filters and summary cards. Ticket controls are grouped into Style, Wording, Artwork and Guest details beside a responsive preview. The exported canvas adds restrained paper/foil treatment and initials derived from actual host names; its dimensions, QR image, quiet zone, credentials and save/export rules remain unchanged. Font initialization now has a recoverable deadline. A browser test decodes the rendered QR and downloads the real 1200 × 1800 PNG.

Application chrome uses one icon-led Khmer/English switch. The duplicate profile-menu language section was removed. Existing language persistence and the separate invitation-authoring language controls are preserved. Mobile, keyboard, light/dark, export, error and unsaved-state checks cover these changes.
