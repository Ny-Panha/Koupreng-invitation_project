# 08 — admin navigation, overlays, and Template Studio adoption

The final baseline run exposed an intermittent subtitle contrast failure while global typography was partly transparent. Automatic reveal/cascade rules were removed from operational headings, subtitles, generic cards, page children and table rows. Explicit feature-owned animation classes remain available. This makes text and authoritative data readable on first paint rather than relying on an axe scan after settling.

The admin app keeps CSS transitions and receives the mirrored motion tokens; **Framer Motion was not installed**. `AdminPageHeader` and `StatCard` no longer hide operational text while staggered entry animations finish. KPI progress width is static. `AdminDashboardPage` and `CoreMetricsBox` now show operational cards and values without cascaded entrance delays; muted small text was darkened after axe found low contrast. `AnimatedNumber` defaults to immediate current values, including financial figures; optional count animation has a tested runtime reduced-motion snap and frame cleanup. `ActionButton` has fixed geometry with tokenized color/opacity feedback. These shared components are consumed by dashboard, templates, packages, reports, and detail routes. Admin status labels remain text, so PENDING/REVIEW/VERIFIED do not depend on animated color.

Template Studio's five section controls, device toggles, preview frame, resize alternatives, and trusted iframe protocol were **preserved**. The new browser case rapidly switches Edit/Preview in 844×390 and returns by keyboard; it checks that fixture data is not written. Existing Phase 04 tests remain the regression baseline. Error toast persistence and destructive confirmation behavior remain with their existing owners; no animation was added to imply save or approval success.

This is `IMPLEMENTED` shared chrome with `FIXTURE VERIFIED` selected routes after the [test matrix](13-browser-and-unit-test-matrix-exact-commands.md) runs. Full admin overlay, audit/report failure, short physical landscape, and screen-reader journeys are `NOT TESTED` and remain Phase 06/22–25 gates.
