# Gallery audio media maps and degradation

Audit started 18 November 2026; continued 19 November 2026 (Asia/Bangkok). Independent local fixture/source evidence only.

Boilerplate, WithJoy, DigitalYes and shared GalleryGrid now use the existing stacked Modal behavior for initial focus, keyboard containment, inert background, Escape and opener return. Original paper/photo composition remains family-owned. Native gallery buttons and visible arrows provide a pointer-free path; image position is announced. Bliss uses the same isolation while keeping its real child mounted so closing/reopening or switching language retains draft input.

Other families use existing native/shared dialogs. Their original tests and new family paints are retained; not every alternate gallery/map presentation and nested-removed-trigger sequence has fresh end-to-end proof. Empty/broken image and image-list changes are explicitly bounded in the state ledger.

Existing audio controllers retain gesture/promise/error semantics. The degradation fixture rejects play promises, blocks selected font/video resources and supplies missing imagery; it is not proof that physical iOS autoplay succeeds. The shared music hook’s existing tests cover stale play results, source changes, pause/error and unmount. Default-track rights remain open.

Venue diagrams are uploaded illustrations, not live Google maps. Existing saved directions/embed URL contracts remain; no coordinates, Maps key, booking capability or provider access was invented.
