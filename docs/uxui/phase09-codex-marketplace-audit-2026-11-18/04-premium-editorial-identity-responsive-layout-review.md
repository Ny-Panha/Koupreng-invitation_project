# Chapter 04 — Premium Editorial Identity & Responsive Layout Review

## 1. Atelier Aesthetics & Cultural Harmony

The Phase 09 experience embodies the Cambodian invitation atelier identity:
- **Palette:** Refined ivory/cream canvas (`#fffcf7` / `#fffaf3`), deep forest ink (`#1f2b24` / `#245740`), and ceremonial warm gold accents (`#B0926A` / `#c3a26b`).
- **Typography:** Ceremonial `Moul` serif headlines paired with balanced, readable `Kantumruy Pro` body typography.
- **Divider:** Subtle ceremonial gold diamond divider (`.tp-divider`) separating atelier title from orientation copy.

## 2. Responsive Grid Behavior

- **Desktop (>= 1024px):** 3-column grid (`.tp-grid`), max-width 1400px centered, 40px gutter.
- **Tablet (600px - 1023px):** 2-column grid, responsive reflow, preserved card aspect ratio.
- **Mobile (< 600px):** 1-column layout, edge-to-edge comfortable touch cards, sticky filter toolbar.
- **Short Landscape (844x390, 820x430):** Header padding optimized to avoid clipping content; modal previews maintain reachable outer scroll and close actions.
