# Mutation authority and revocation

Independent revalidation: 19 November 2026, Asia/Bangkok. Scope: local source, adapters and named fixtures.

The server access response remains authoritative for workspace actions. Grant revocation disables fields and Save while preserving the dirty form for recovery. Request cancellation binds a write to one mounted document/session/grant, even when the user changes account before Axios adapter dispatch. The independent pre-fix adapter captured the actual forbidden combination of A bytes and B Authorization; after repair no write reached the adapter.

Server-owned entitlements, prices, guest-token privacy and owner-only publish policy were preserved. A 403 is now denied, with retry suspended rather than disguised as a transient connection error. Full backend tests add unit/H2 contract confidence, but 82 configured skips retain external MySQL/live-provider limits. UI affordances are never presented as proof that an unauthorized direct endpoint is secure in a live environment.
