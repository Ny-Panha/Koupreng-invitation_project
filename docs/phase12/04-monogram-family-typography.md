# Monogram, families and typography

The existing text/vector maker gains four curated starting styles: round initials, oval petals, minimal signature and diamond frame. They compose existing allowed frames and motifs, preserve authored initials and remain subject to the existing `COUPLE_MONOGRAM` server entitlement. No uploaded SVG, remote logo or new religious/royal seal is introduced.

Font choices now name actual bundled faces: Moul, Kantumruy Pro and Cormorant Garamond with Khmer fallback. The former generic serif selection uses the licensed bundled English display face. Monogram lines split on grapheme boundaries, adapt size to long text and preserve Khmer combining marks. Short initials are recommended for small display sizes. Petal geometry is original; more culturally specific carved/temple motifs await editorial review.

Safe local SVG and PNG export use the shared vector boundary and embedded OFL metadata where font bytes are distributed. The UI explains that the graphic is decorative and not trademark certified. No canvas or SVG upload bypass is added. Export buttons require authored text.

Family editing explains empty groups and existing-parent fallback, labels first/second partner families, and keeps explicit names, relationships and honorifics. Checklist links identify family fields without changing account language. Royal Lotus no longer prepends inferred male/female titles or strips an authored title from a parent line. Empty optional closing fields now retain their explicit emptiness there.

Existing balanced/reversed/stacked/centered placements remain capability-scoped. CSS changes visual placement while groom/first partner and bride/second partner stay in canonical DOM order. Existing narrow-screen stacking and long-name wrapping are preserved. No new animation or unsupported layout option was added. Native typography review remains pending; component/browser evidence and representative actual screenshots are supplied separately.
