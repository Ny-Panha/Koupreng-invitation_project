# 13 — visual evidence and performance

The local `capture-visual.mjs before|after` harness built isolated apps, served loopback previews and captured **52/52 before + 52/52 after** fictional fixture screenshots with zero browser page errors in each manifest. Files under `output/playwright/uxui-phase04-2026-11-11/` are ignored; tracked [before](evidence/before-manifest.json), [after](evidence/after-manifest.json) and [pixel diff](evidence/capture-diff.json) indexes contain paths, SHA, browser, viewport, locale and fixture metadata. Thirty-seven screenshot pairs are pixel identical. Four admin and three owner pairs have changed pixels from management styling or capture timing. Sixteen of 24 renderer captures are identical; eight differ by 0.065–6.323%, across four families. No renderer source changed. The renderer differences are **REVIEW REQUIRED**: timed/font capture variance is possible, but an artwork regression has not been ruled out. A visual reviewer should inspect the paired images before clearing them.

The [local lab summary](evidence/lab-summary.json) contains 60 runs: five fixture routes × cold/warm × before/after × three repetitions at 390×844, reduced motion, unthrottled loopback Chromium. User total built CSS/JS gzip was 1,192,998 → 1,193,235 bytes (+237); admin was 342,737 → 342,986 (+249). User initial index CSS gzip fell 41,280 → 41,258 bytes; admin index CSS gzip rose 28,241 → 28,489 bytes (+248), while the measured initial admin JS file was 89,598 → 89,593 bytes. No new dependency was added.

Median local load examples: admin dashboard cold 59.8 → 39.0 ms; Studio cold 64.2 → 38.3 ms; home cold 77.1 → 77.8 ms, but warm 53.2 → 150.3 ms. Home cold FCP/LCP had only 1/3 valid before samples and home warm after had 2/3; the home variance is **REVIEW REQUIRED** and cannot be attributed to this small component diff without repeat runs under controlled CPU/network conditions. The summary records FCP, LCP, CLS and sample counts for all ten route/condition pairs. No INP was measured and none of these loopback values are field Core Web Vitals.
