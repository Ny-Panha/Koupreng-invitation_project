# Studio, renderer and locale coverage

[Machine-readable matrix](evidence/studio-template-locales-matrix.json) is generated by `phase12ContractMatrix.test.jsx` from the current `TEMPLATES`, registry and capability function. It contains 13 catalogue/neutral presentations, two content locales, 24 field families and ten journey stages. Aliases are retained as catalogue presentations, not counted as independent rendering engines.

Every cell uses `SUPPORTED_VERIFIED`, `SUPPORTED_DEFECT`, `UNSUPPORTED_BY_DESIGN` or `NOT_TESTED`. The component run verifies public-adapter rendering of couple names, invitation wording, venue, schedule, family, monogram and illustrated map wherever advertised. It does not mark a component render as an HTTP save. Other individual field/stage combinations remain explicitly untested in this matrix; the regression suites supply additional scenario evidence without pretending to cover every Cartesian combination.

`phase12-matrix.spec.js` consumes the generated inventory. For each presentation it exercises Khmer-only publication fixtures with draft suppression and complete bilingual fixtures with guest switching, retained canonical RSVP input and unchanged guest-token URL. It checks 320/375/390/430/768/1024/1440/1920 widths in Chromium, Firefox and WebKit. The designed sweep comprises 78 cases and 936 viewport states; report 08 records actual completed results. These browser writes/publication responses are synthetic fixtures.

Real server/database evidence is separate in [backend summary](evidence/backend-summary.json). Fifteen collaboration HTTP tests and four media HTTP tests exercise a servlet server against new disposable MySQL, alongside five upgrade tests. The added Phase 12 journey saves/reopens/publishes two program days, stable rows including `none`, bilingual wording, explicit empty apology, family groups, monogram and a structured route; it checks 409 retry rejection, stable access identity, collaborator denial after owner downgrade, cross-event denial, public benefit suppression and private recovery. Other existing cases cover expiry, publication authority, legacy replacement and concurrent locale writers.

The matrix caught a real P0 gap: WithJoy and Bliss discarded the canonical hosted RSVP child and rendered their local catalogue demo form. Both now render the supplied canonical form. Bliss keeps the component mounted while its drawer is closed, supports Escape and focus cycling, and restores focus. Dedicated component and browser cases verify retained input through a language change. Unsupported family/monogram controls and retained source data remain governed by capabilities.
