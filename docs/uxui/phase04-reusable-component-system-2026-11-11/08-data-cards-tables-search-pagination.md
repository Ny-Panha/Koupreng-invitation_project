# 08 — data, cards, tables, search and pagination

The organization member table now exposes a named focusable scroll region around its existing semantic table. This makes horizontal scrolling reachable by keyboard while retaining its table name and cells. Its table surface, header, borders and body text consume management theme roles; the focus indicator uses the Phase 03 focus role and the system `Highlight` color in forced colors. A unit test checks the region/table structure and a real organization-detail browser fixture verifies horizontal overflow and ArrowRight scroll movement at 320px in desktop and mobile Chromium. Guest and delivery tables use the same primitive. Guest/RSVP search inputs use the updated shared search styling.

Admin `StatCard` now takes surface, border, text and hover gold from theme roles. Its value and semantic tone inputs are unchanged; existing dashboards/templates/packages consume it. Colored tone icons and progress gradients remain legacy palette choices and need contrast review. Admin `DataTable` and `FilterTabs` have no source consumer found, so neither is presented as adopted. Search, filter, pagination, selection and bulk toolbar families are still route-specific; their full state/a11y contracts remain later work. No table data or totals were invented or recalculated.
