# Accessibility, contrast and visual QA

The unit contrast test calculates WCAG ratios for management body, muted, action, warning, danger, Studio selected control and focus roles. Representative computed values from 390px Chromium after capture: Home light `rgb(31,36,33)` on `rgb(251,246,238)`; Home dark `rgb(240,243,238)` on `rgb(23,32,25)`; auth dark input `rgb(240,243,238)` on `rgb(32,42,36)` with `rgb(130,152,131)` border; owner dark muted button `rgb(185,199,186)` on `rgb(32,42,36)`. Studio chrome text is `rgb(240,243,238)` on `rgb(17,23,25)`. These are actual browser computed styles, not a universal assertion about every descendant.

Calculated role pairs: gold `#926c34` on white **4.75:1**; muted `#59615c` on cream **5.93:1**; dark muted `#b9c7ba` on `#172019` **9.50:1**; dark gold `#d9b879` on `#202a24` **7.82:1**; Studio selected ink `#19271e` on gold **8.21:1**; warning `#ffd18a` on `#3b2c11` **9.48:1**; danger `#ffb4ab` on `#402826` **7.98:1**. The code test enforces ≥4.5 for normal text pairs and ≥3 for focus. For translucent overlays the final composited page must be measured separately.

Five selected `@axe-core/playwright` WCAG-tag scans after the auth contrast fix reported **zero rules**: Home light, auth dark, owner dashboard dark, admin dashboard light and Studio dark. The first scan found two dark auth nodes at 2.31:1 and 3.11:1; their selectors `.auth-divider` and registration link were remapped to theme-muted/link, and the repeat scan was clean. The final raw rule report is `evidence/responsive-a11y-results.json`.

The 95 breakpoint probes found no document overflow. Studio short-landscape Edit/Preview switch and outer scroll were tested. The capture set uses `reducedMotion: reduce`; current focus rings are source-backed (3px) and existing toggle semantics are untouched. This work does not replace manual keyboard traversal, screen-reader announcements, modal focus restoration, 200% actual browser zoom, forced colors, native Khmer diacritic review or physical touch testing. Those checks are [open gates](14-open-gates-decisions-and-limitations.md) and Phase 04/06/25 component work.
