# Publish review and private/public truth

Independent revalidation: 19 November 2026, Asia/Bangkok. Scope: local source, adapters and named fixtures.

Publish Review still evaluates required fields and visibility, flushes the current draft, and requires a server PUBLISHED response before displaying success or constructing a share URL. Preview does not invoke publish. The request now carries the same cancellation authority as saving, and late publication/status results cannot confirm another account’s event.

The functional negative edits a dirty title, confirms review, intercepts a 503 publish response, verifies the error and asserts there is no published result. This is explicitly a fixture server acknowledgement journey. Real public access, unpublished/already-published transitions and live cookie/MySQL races remain Phase 15/staging validation gates. No guest message, payment settlement, public deployment or new access semantics were performed.
