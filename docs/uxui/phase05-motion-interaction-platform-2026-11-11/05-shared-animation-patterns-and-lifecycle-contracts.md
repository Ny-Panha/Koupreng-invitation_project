# 05 — shared patterns and lifecycle contracts

**Route ownership:** The global `RouteMotion`/`SiteAnimations` layer was removed. It previously supplied a full-screen logo preloader, pointer `requestAnimationFrame` loop, route pulse, and reversible hidden reveals. Venues already owns `ScrollReveal` and its own Framer entrance; its only page section contains interactive controls, so a proposed generic observer had no eligible content and was removed before publication. Marketing and dedicated invitations keep their existing route/family-owned effects. Auth, payment, owner, admin, and guest tasks no longer inherit a generic curtain.

**Guest gate:** `TemplateExperience` owns `closed → opening → opened`. For ordinary shared gates, the Open click requests audio during browser user activation; the timer only completes the visual state. The existing cinematic provider defers its music callback until its video completes, so audio permission in that path remains a device-review gate. `TemplateOpeningGate` exposes an optional 44px Skip button even during opening, using the invitation's English/Khmer mode before the site language fallback. Skip cancels the timer and cinematic stage, reveals content, and does not request music. Reduced motion changing mid-opening follows the same completion path. Video pauses on cleanup and does not auto-play under reduced motion. The existing registry, iframe preview trust, and serializer are unchanged.

**Management feedback:** `AnimatedNumber` defaults to the current authoritative number; motion is opt-in only for suitable nonfinancial counts. An opt-in frame is canceled and snaps to the target when reduced motion changes. Admin page headers, dashboard cards and metric cells no longer delay operational values or animate progress width. Dashboard table/metric text contrast was raised in the final browser pass. `ActionButton`, user `LoadingButton`, and toast preserve props/ARIA and use the token vocabulary. The host drawer closes by compositor transform and becomes offscreen/inert; explicit dismissal restores focus to its trigger. Existing Modal focus stack and persistent admin error toast remain unchanged.

Unit evidence covers guest Skip/normal/reduced opening, audio failure, admin numeric preference changes, and host drawer inert/focus. Browser evidence is listed in [13](13-browser-and-unit-test-matrix-exact-commands.md). No animation callback writes business state; all changed timers and frames have cleanup paths. Optional route-specific reveal and media policies left in the [route ledger](evidence/route-adoption.json) remain `DEFERRED` to their owners.
