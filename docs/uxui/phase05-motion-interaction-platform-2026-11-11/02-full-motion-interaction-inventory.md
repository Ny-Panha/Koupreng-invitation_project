# 02 — full motion and interaction inventory

The [source generator](evidence/generate-motion-ledger.mjs) parsed **802 JS/JSX/TS/CSS source files** using `@babel/parser` for JavaScript imports, resolved relative and `@/` imports, and recorded CSS `@import` edges. It found **207 files with motion signals** (CSS transitions/keyframes, Framer, observers, timers, frames, media, scroll, drag/resize, or canvas/3D). These are file-level owners, not 207 individually certified visual effects. [Direct/transitive graph](evidence/module-graph.json), [owner rows](evidence/motion-owners.json), and [unresolved imports](evidence/unresolved-imports.json) distinguish verified module edges from route JSX binding gaps. The current scan has **zero unresolved local module imports**; externally supplied modules and runtime/generated route state are not resolved by this graph.

The highest-risk **pre-edit** source owners were `shared/animations/SiteAnimations.jsx` (global preloader, pointer tracking, route pulse, and reversible hidden reveals), `TemplateExperience.jsx` plus `TemplateOpeningGate.jsx` (timed guest gate, audio/video, focus), admin `AnimatedNumber.jsx` and `AdminUI.jsx` (animated operational values and delayed headings), owner `HostNav` (offscreen drawer and focus), and two Studios' tab/preview controls. The global SiteAnimations and RouteMotion files were deleted; see [05](05-shared-animation-patterns-and-lifecycle-contracts.md) for dispositions. Renderer-owned effects remain distinct; the source graph does not grant a universal theme or scene.

The ledger's decision fields use `REFINE` for modified shared owners, `KEEP / family review` for authored invitations, and `DEFER` for route-specific motion left with the primary phase owner. Trigger, duration, interruption, focus, input, and performance behavior vary within a file; a complete per-effect certification requires the Phase 10/16 route/device tests. `SOURCE-MAPPED` here means code was inspected or scanned. Browser tests and screenshots have separate evidence.
