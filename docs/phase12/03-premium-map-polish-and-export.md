# Illustrated venue map

Six original editable presets cover main road, multi-turn, landmarks, intersection, rural road and minimal diagram. They use fictitious generic labels and no copied street topology or tiles. Applying a preset to authored nodes requires explicit replacement confirmation; existing Studio undo restores the prior design. Presets generate independent node IDs and label objects.

The editor adds visible grid/snapping, a drag/scroll toggle, fit-to-canvas, target alignment, right-angle straightening and road connections. Existing duplicate, layer ordering, numeric coordinates, keyboard arrows, undo and redo remain available. Disabling drag cancels an active gesture while preserving keyboard editing. Background touch scrolling is available; node manipulation captures only its gesture. Native touch cancellation remains covered by the Phase 11 regression.

Market, school and pagoda landmarks now have distinct original line details. Labels use larger type, grapheme-safe bounded multiline display, complete SVG titles and a full readable public legend. Very long diagram labels are abbreviated after three displayed lines; their saved text, title and legend remain complete. Initial visual inspection found crowding between destination and parking labels; spacing and label bounds were corrected before the final captures.

Maps retain v1, existing palettes/aspect ratios and the 80-node limit. No new database schema, SDK or map service is introduced. The public diagram remains a host-authored schematic, explicitly separate from the validated directions link. Current-owner Premium checks and expiry suppression remain server-side; private source is retained.

`vectorExport.js` accepts only generated vector DOM, rejects executable/external elements and paint resources, strips editor affordances and bounds dimensions. SVG embeds bundled Moul, Kantumruy Pro and Cormorant Garamond font bytes with their OFL metadata. PNG/WebP draw shapes locally and shape text directly with loaded local FontFace bytes; this avoids relying on browser-dependent embedded-font behavior in SVG image contexts. No remote image, tile or user-supplied SVG is loaded. Object URLs are revoked. Unsupported export formats fail visibly without disabling SVG.

Implementation research: [MDN SVG image restrictions](https://developer.mozilla.org/en-US/docs/Web/SVG/Guides/SVG_as_an_image) and [canvas origin restrictions](https://developer.mozilla.org/en-US/docs/Web/HTML/How_to/CORS_enabled_image). [Export evidence](evidence/exports/) includes actual browser-produced SVG/PNG/WebP, not illustrative mockups. Browser cases validate signatures/dimensions, local Khmer text, replacement confirmation, undo, disabled dragging, fit, save and reopen in all three engines. Physical touch devices remain pending.
