# Rendered review and asset provenance

Baseline captures use the untouched initial commit `17484e58` in a separate detached worktree. The baseline browser command passed two cases and wrote 12 images under `evidence/before`: family, program and venue at 390/1440 px, KH/EN. After captures under `evidence/after` include custom family/monogram, program, schematic diagram, guest switcher and actual Studio controls. Fixtures contain fictional people/venues only.

The agent visually inspected the baseline phone family and desktop venue, and the resulting Khmer/English family, Khmer/English diagram, English program and Studio map/monogram images. Findings: long Khmer names wrap and keep semantic partner order; English family text uses readable Latin typography; monogram remains decorative; mobile family stacks; program time and ceremony text remain readable; the diagram has an extended description and textual label legend because overview labels become small on phones. The Studio capture shows the actual editable vector canvas, not a mockup.

The before and after fixtures intentionally exercise different authored feature content. These are controlled engineering review captures, not identical-data pixel goldens. Existing floating ticket UI remains visible in cropped captures and can overlap the crop at the viewport edge. No blanket pixel-perfect, native-device or full WCAG certification is claimed. Browser overflow checks cover the eight required widths; Axe scopes and exact results are in report 10.

New art: original React/SVG geometric monogram frames/motifs and schematic nodes. No reference screenshot art, names, phone numbers or real geography were copied. No generated raster asset, external map tile, branded logo or geographic data was added. Ceremony symbols reuse the installed Lucide library; its package LICENSE is available locally. Export embeds `public/fonts/silk-heritage/KantumruyPro.woff2` and `KantumruyPro-OFL.txt`. Existing Moul and Cormorant local fonts retain their adjacent OFL files. Existing template floral/photo assets are inherited unchanged; this work does not assert a new independent license audit of that catalogue.

Performance evidence uses controlled Vite production builds on the same machine. Initial main entry: 444.90 kB / 130.54 kB gzip; initial Studio route: 169.79 kB / 44.71 kB gzip. Final measurements are recorded in report 10. Route splitting remains in place; no map SDK, remote tile runtime or new drawing dependency was installed. No Lighthouse, INP, CLS, heap disposal or low-end physical-phone measurements were obtained.
