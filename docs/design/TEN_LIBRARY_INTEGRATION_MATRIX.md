# Ten-library UI research and selection matrix

Reviewed **2026-11-04** against official documentation and linked upstream repositories. This is a selection record, not a claim that ten libraries have been installed. Batch one imports **no third-party component source** and adds **no runtime dependencies**. Proposed paths below refer to existing Koupreng components; future adoption still needs a component-specific review and verification.

The existing stack is React 19, Vite 8, Tailwind 4, JSX, native shared controls, and `framer-motion` in the customer app. The admin app has no animation engine. Neither manifest currently declares Radix, Base UI, React Aria, or a shadcn component foundation. Replacing working controls wholesale would introduce overlapping systems and invalidate their existing behavior tests.

Performance risks in this document are engineering estimates based on the inspected dependency/effect model, **not measured benchmark results**.

## Selection gates for later batches

1. Identify the exact existing usability problem, route, component and behavior contract. Prefer an existing shared primitive.
2. Open the exact component source, its registry dependency list, and the applicable license at the selected revision. Documentation availability is not source redistribution permission.
3. Record a pinned upstream revision, local destination, modifications, all required notices, and whether it is reachable by a builder or customer-exportable output in [THIRD_PARTY_UI_LICENSES.md](THIRD_PARTY_UI_LICENSES.md).
4. Reject paid/unlicensed code and incompatible restrictions. For independent implementations, do not copy upstream source, markup, assets or distinctive branded composition.
5. Reuse existing CSS and `framer-motion` when they solve the need. Avoid Next.js APIs in either Vite app. Import only the selected component, never a catalogue bundle.
6. Verify behavior, keyboard/touch access, responsive layout, live reduced motion, API state fidelity and production bundle impact before marking any route complete.

## Research boundaries

Official documentation and repository license files above were read; this is not an exhaustive audit of every component in each upstream catalogue. Skiper's public GitHub footer links to the author's profile, not a verified complete component repository; its catalogue was client-rendered in the text browser. Its Quick Start provides commercial usage/attribution guidance, while its general site terms are broader. Lightswind's site and repository describe different restrictions. These uncertainties block copying those sources, **not** original local UX improvements. A later source import must resolve its exact scope first.

No external screenshots, photographs, fonts, icons or marketing assets were downloaded from these libraries for this batch. Existing Koupreng brand assets and existing installed dependencies remain the implementation foundation.
