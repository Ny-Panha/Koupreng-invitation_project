# Bundle and runtime evidence

Independent revalidation: 19 November 2026, Asia/Bangkok. Scope: local source, adapters and named fixtures.

The unchanged entry source was built before product edits, then the reviewed source was built with the same installed Node/lockfile. Entry InvitationEditFeature was 241.35kB raw / 63.13kB gzip; the latest build log records current emitted sizes. The separate InvitationStudio chunk is not a substitute for the full editor route chunk. No dependencies were added. Small growth pays for session cancellation, JSON preservation and truthful recovery.

These are emitted-asset observations, with exact current file hashes/bytes retained locally. Build durations ran under different host load and are not a cold/warm performance experiment. No p95 typing latency, field INP/CWV, memory/object-URL lifetime or universal opening budget is invented. A late CSS-only compact-height refinement was rebuilt during broader compatibility replays; those replays are not frozen performance evidence. The final Studio browser run uses the subsequent fixed build.
