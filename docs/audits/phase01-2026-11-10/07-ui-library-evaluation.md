# Ten React UI library adoption matrix

Verified against official sites/repositories on 10 November 2026. Mobile/desktop and performance ratings below are **engineering assessments of candidate patterns**, not claims that every upstream component was device-tested. No upstream packages or source were installed during this audit. Current stack: React 19 JSX, Vite, Tailwind 4, Framer Motion, project-owned CSS and primitives.

## Identity and maintenance evidence

Public GitHub repository metadata was fetched without authentication and saved in [library-maintenance.json](evidence/library-maintenance.json). All eight queried repositories were non-archived at retrieval. Recent push dates indicate activity, not support guarantees. Animate UI/shadcn/Untitled/Magic had November 9 pushes; Kokonut/React Bits November 8; Badtz February 27. Lightswind's exact push timestamp is recorded in that JSON. Aceternity and Skiper have reachable live catalogs/docs; an independent current commit cadence was not verified. Badtz's published changelog is older than its repository activity, so do not infer weekly maintenance from marketing copy.

## Compatibility and adoption gate

Seven adapted components already exist under `apps/frontend-user/src/shared/ui/vendor/`. The existing `docs/design/THIRD_PARTY_UI_LICENSES.md` contains source/license provenance and runtime/export restrictions; preserve it and verify exact pinned terms before copying anything new. Existing project annotations are not legal clearance for every current upstream component.

Adoption requires a demonstrated product need, a pinned source and license notice, necessary dependencies only, mapped semantic tokens, mobile/desktop keyboard/touch checks, reduced-motion behavior, and before/after bundle evidence. Default to Lucide and existing Framer Motion. Do not add GSAP, another icon family, CSS resets, smooth-scrolling engines or a second component framework solely to claim all ten were used. All ten can inform design judgment without all ten shipping code.
