# Chapter 10 — Khmer / English Language, Typography & Copy Review

## 1. Bilingual String Parity

All marketplace strings are localized via `marketingMessages.js` and local copy helpers.
- **Header:** "A design that feels like you." / "រចនាបទដែលជារបស់អ្នក។"
- **Eyebrow:** "The invitation collection" / "គំរូសន្លឹកការប្រណិត"
- **Filters:** All ("ទាំងអស់"), Free ("ឥតគិតថ្លៃ"), Premium ("ប្រណីត")

## 2. Typography & Khmer Script Safeguards

- Correct line-height and padding prevent clipping of Khmer subscript consonants and combining vowels.
- Clean font fallback: `'Moul', serif` for headlines; `'Kantumruy Pro', sans-serif` for UI elements.
