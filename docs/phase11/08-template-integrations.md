# Capability-aware integrations

The original registry has 36 keys including aliases. Coverage uses the actual 11 catalog entries plus neutral Event Essential, not a claim of 36 independent visual designs. `feature-contract-matrix.json` is generated by rendered DOM probes for each catalog entry in KH and EN, and records map/family/monogram output plus retained source.

Family layout and monogram support: Silk Heritage, Khmer Celestial including Royal Khmer alias, Royal Lotus, Golden Canva including its supported catalog alias, and the shared Garden/demo engine. Digital Yes, Emerald Luxe, WithJoy, Bliss and Boilerplate retain their authored feature data with explicit capability exclusions for those two controls. Their existing couple/family presentation remains available.

Illustrated maps render in the actual venue sections of supported renderers and neutral Event Essential. Boilerplate lacks that venue/schedule capability and excludes the map maker. Event Essential does not force wedding family roles or monograms; its dedicated localized event editor retains shared dates/contact data and supports a Premium schematic map.

Adapters explicitly carry design fields instead of adding a Celestial-only side channel. Family and diagram components are inserted only at compatible semantic sections. Existing renderer openings, galleries, video, gifts and tickets retain their original paths. Static labels use the display locale while authored content is projected separately.

Playwright covers all 12 catalog/Event Essential presentations, two approved locales and eight widths (320, 375, 390, 430, 768, 1024, 1440, 1920) in each available engine. This is 576 viewport states across Chromium, Firefox and WebKit when all 72 matrix cases pass. It checks title/venue delivery and document overflow; it is not 576 independent HTTP persistence journeys or pixel-perfect certification of every section.
