# Routes, editor modes and authority partitions

Independent revalidation: 19 November 2026, Asia/Bangkok. Scope: local source, adapters and named fixtures.

hostRoutes keeps RequireAuth around the host shell. EventInvitation selects the advanced editor only for WEDDING events whose template is not event-essential. Other events continue through EventDetails. Numeric legacy edit links redirect to the canonical event workspace; nonnumeric local continuations use the owner-scoped loader. No new non-wedding advanced editor exists.

EventWorkspace keys its verified lifetime by account/event and derives controls from the actual access response. Studio recovery may retain dirty text after revocation, while fields and Save are disabled. The legacy loader now has an equivalent account/id lifetime key, preventing the old invitation from painting during another account’s load. API mutation authority remains server-owned. The route matrix records these partitions rather than claiming every Cartesian combination was executed.
