# 12 — performance, bundle, and motion lab results

The [fixture lab script](evidence/measure-lab.mjs) runs isolated pre-edit and post-edit production builds from [the capture index](evidence/capture-index.json). The pre-edit build was made from clean `f26c83293f01a2845fde37fccaa5dd0fbe03737e`; the post-edit build was made from the Phase 05 worktree. It uses Chromium on loopback with the same fictional Batch 12 read-only route DTOs, no external resource requests, a `Date`-only wall clock fixed at `2026-11-11T12:00:00Z` (native performance clock), DPR 1, 390×844 and 1440×900 viewports, CDP 2× CPU throttle, 20ms network latency, 10Mbps down and 5Mbps up. Each surface/viewport/motion state runs in a fresh browser context: first navigation is cold, second navigation is warm. Reduced and normal motion each have three trials. Fonts are awaited, the page is allowed 400ms after `load`, and a screenshot consumes the headless paint before metrics are read. No Phase 04 build artifact is used in this comparison. An initial instrument run using Playwright's fixed clock was rejected because it erased navigation, paint and resource entries; its raw output is preserved locally as `lab-results-instrument-v1.json` and excluded from the summary.

The 13 selected surfaces are home, catalog, login, create event, owner dashboard, invitation, admin dashboard, admin Template Studio, ordinary invitation, cinematic invitation, checkout, payment status, and RSVP. The tracked [lab summary](evidence/lab-summary.json) gives condition-level valid counts, medians, minimum/maximum, LCP element tag, resource transfer bytes, and build asset totals. Each metric needs three valid observations in its own condition; otherwise it is `INSUFFICIENT DATA`. Raw navigation/resource entries and individual JS/CSS asset sizes remain in ignored `output/playwright/uxui-phase05-2026-11-11/lab-results.json`. The [summary script](evidence/summarize-lab.py) regenerates the tracked result.

The lab measures `load`, FCP, LCP, CLS, long-task count/duration and resource transfer as browser API approximations. The bundle inventory records total emitted JS/CSS files plus gzip and Brotli sizes; **all emitted assets are not an initial route payload**. The per-navigation resource records are the route payload proxy. Neither the lab nor the browser functional suite measures field p75 LCP/INP/CLS, controlled interaction latency, animation frame jank, memory, decoded media cost, or a real mobile radio/GPU. Those remain `NOT TESTED` and cannot be inferred from a low loopback load time. The 2.5s LCP, 200ms INP and 0.1 CLS figures are field goals, not a claim of compliance.

For this lab, an after median exceeding the matching before median by both **100ms and 20%** for load/FCP/LCP, or by both **20KiB and 10%** for initial transfer, triggers review. A CLS increase above **0.02** also triggers review. These are diagnostic change budgets for matched local conditions, not field pass thresholds. Three observations are a minimum; a wide min/max spread or a missing sample weakens attribution even when a median is below the trigger.

## Controlled comparison

The corrected run completed **624/624 navigations with zero errors**: 13 surfaces × 2 viewports × 2 motion settings × 2 cache states × 3 trials. All seven summarized metrics have three valid observations in every condition. See the [machine-readable condition table](evidence/lab-summary.json) for the full matrix. The Phase 04 home warm-load variance was roughly 53.2ms → 150.3ms in an unthrottled local loopback series and lacked complete paint samples. ## Performance disposition

The source change removes the global pointer `requestAnimationFrame` loop, logo preloader, route pulse, and hidden reversible reveals. Venues retains its page-owned `ScrollReveal`; the attempted generic route observer was removed because it had no eligible sections. Admin operational values render immediately; no count-up is required for financial data. The isolated build inventory and route resource observations show no unexpected eager Framer or guest-media loading on home. This source reasoning is `IMPLEMENTED` but is not a measured FPS or field result. The six triggered timing conditions and the unmeasured interaction/frame/field metrics remain review gates.
