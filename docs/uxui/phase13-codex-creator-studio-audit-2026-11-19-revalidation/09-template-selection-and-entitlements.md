# Template compatibility and server entitlements

Independent revalidation: 19 November 2026, Asia/Bangkok. Scope: local source, adapters and named fixtures.

TemplateChooser separates public catalog visibility, renderer availability, language/event compatibility and paid access. Catalog failure presents preview-only designs with retry; it does not authorize selecting a fabricated template. The form fetches the fresh template identity, checks server access, confirms the change, and retains authored form data.

Each asynchronous template-selection stage now verifies the same Studio request authority before applying a late result or opening feedback. This protects account/grant changes during catalog/access confirmation. Server prices and premium entitlements were not modified. Existing policy/chooser/backend tests and actual chooser focus are current evidence. Exhaustive paid A→B→A journeys across every renderer remain partial, and no permission is inferred from the visual premium badge.
